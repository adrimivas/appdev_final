Hello! We are so happy you are using Got the Dough? It is a financial analysis app that helps you keep track of your debts, plan out investments, make budgets, and more! 
Disclaimer: This app is not a financial advisor, but a self-help tool for users to keep track of some of their finances. 

Here are a few things you should know. 
Some of the features that the app includes are:
- The ability to create an account and have it keep your data
- A Profile Page that shows important information like income, expense to income ratio, debts, and more
- Advice Page that gives you investment or debt removal advice depending on user's specific situation
- Investment Page that shows possible returns depending on investment method
- Debt Page that shows user's current debts with detailed information regarding them
- Calculator Page that has three tools: Monthly Budget Planner, Debt Calculator, and Emergency Fund Calculator


Setup Instructions
- Install all of the files of this app
- Run npm install then npm reactor-reactor-dom on financial_app_tool directory
- In a split terminal, run node server.js from financial_app_tool directory on one terminal and on the second terminal, run npm run dev from moneyApp directory
